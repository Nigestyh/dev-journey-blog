What I Learned Building an Etch-a-Sketch

Oct 14, 2026 · JavaScript · DOM Manipulation & Events

| View code · Live demo

I created this project as part of The Odin Project's curriculum to put what I had learned about event handling and DOM manipulation into practice. I wanted to see how these concepts worked together when building something interactive.

Challenges I Had

  • When the cursor reached the end of the grid, the grid container and the web page would turn red.
  • Keeping the logic for handling paint, erase and rainbow mode inside the event handler made the code feel cluttered.

What Helped

The issue occurred because I was listening for the mouseover event on the parent container. Due to event delegation, when the cursor hit the edge of the grid, the container itself became the event.target, causing the background colour to be applied to the entire container and page.

 
//Before
                        
containerElement.addEventListener("mouseup", () => {
isDrawing = false;
});
                        
containerElement.addEventListener("mouseover", (e) => {
if (!isDrawing) return;
                        
e.target.style.backgroundColor = "red";
 });

            

//After
                        
containerElement.addEventListener("mouseup", () => {
isDrawing = false;
});
                        
containerElement.addEventListener("mouseover", (e) => {
if (!isDrawing) return;
                        
if (e.target.classList.contains("square")) {
e.target.style.backgroundColor = "red";
}
});

To fix it, I added a check to make sure the event was only applied to the individual grid squares. This meant that if the mouse moved over the container itself, nothing would happen.

And to clean up the code, I moved the logic for painting, erasing, and rainbow mode into a helper function.

What I Learned

This project taught me to pay attention to where an event is being listened for, especially when working with mouse interactions such as mousedown, mouseup, and mouseover. I also learned how using a helper function to handle different tools in one place can help keep the code clean and easier to maintain as the project grows.

Next Step

Originally, I built it around mouse events. My next step is to use Pointer Events so the project works with different input devices.
