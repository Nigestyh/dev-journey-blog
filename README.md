# dev-journey-blog

A developer blog and learning log focused on honest reflections, lessons learned through building, and practical advice to help other self-taught developers.

## The Purpose

Halfway through 2026, I looked back at my 2025 calendar and noticed that week after week, all I did was "Learn" — watching tutorials, reading documentation, and taking notes. However, very little of that turned into real projects I could see, use, or build on. I had fallen into the trap of continuous learning without practice.

To break this loop, I decided to stop passively learning and start building. This blog was created to solve that problem. It serves two core missions:

1. **For Me:** A personal space to document what I build and what I learned, creating a tangible record of my progress.
2. **For Others:** An honest space to help self-taught developers escape the learning loop and focus on building real projects.

## Layout

The platform is fully responsive. A clean minimalist design, custom-built mobile hamburger navigation, and integrated code syntax highlighting.

- **Main Hub (Homepage):** Features my latest learning log highlights, a showcase of my projects, and a navigation to my about me page.

- **Learning Logs (Article):** A single-page article of a project I've built, what I struggled with and I took away from it.

- **About Me:** A personal page sharing my story and why I built this project.

## Tech Stack

- **Structure:** Semantic HTML5
- **Styling:** Accessible, mobile-responsive CSS3 using Flexbox/Grid, and Media Queries
- **Interactivity:** Vanilla JavaScript
- **Formatting:** Prism.js (Syntax highlighting for code snippets)
